# Shift handoff template

Write one at the end of each shift so the next analyst knows exactly where things stand. Keep it short and factual.

## Shift
- Date and time window:
- Analyst:

## Data health
- Are `winlogs` and `linuxlogs` ingesting normally? Any gaps?
- Any alerts that did not run or errored?

## Open cases
| Alert | Severity | Account / host | Status | What was done | What is next |
|---|---|---|---|---|---|
| | | | | | |

## Closed this shift
| Alert | Decision (FP / benign TP / TP) | Reason |
|---|---|---|
| | | |

## Escalations
- Who it went to, when, and what evidence was attached.

## Tuning changes
- Which alert, what changed, and why (threshold, allowlist, exclusion).

## Watch items
- Anything unusual that did not meet an alert threshold but is worth watching.

## Notes for the next shift
- Anything else they need to know.
